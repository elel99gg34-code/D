# 백귀야행 百鬼夜行

수묵화풍 **로그라이크 덱빌딩 게임**. 파일 하나로 돌아간다.

```
game/index.html  ←  브라우저로 열면 끝. 서버도, 빌드도, 외부 리소스도 없다.
```

퇴마사가 되어 요괴가 들끓는 산을 오른다. 부적(카드)으로 싸우고, 갈림길을 골라
올라가며, 덱을 다듬어 세 봉우리의 주인을 넘어선다.

쓰러져도 처음으로 돌아가지 않는다. 마지막 갈림길로 되돌아가 다시 서면 된다.

---

## 실행

```bash
# 그냥 열기
xdg-open game/index.html      # 리눅스
open game/index.html          # macOS
start game\index.html         # 윈도우

# 혹은 로컬 서버로
python3 -m http.server 8000   # → http://localhost:8000/game/
```

의존성 0개. 이미지·폰트·오디오 파일을 하나도 쓰지 않는다.
그림은 전부 CSS/SVG로 그리고, 효과음은 WebAudio로 그때그때 합성한다.

## 조작

| | |
|---|---|
| 카드 사용 | 카드 클릭 → (대상이 필요하면) 적 클릭 |
| 취소 | 우클릭 / `Esc` |
| 단축키 | `1`~`9` 카드, `E` 또는 `Space` 턴 종료, `D` 덱 보기 |
| 메뉴 | 우상단 `≡` — 소리, 진행 속도, 덱, 모험 포기 |

진행 상황은 자동 저장된다(localStorage). 타이틀에서 *이어서 오르기*.

**쓰러져도 모험은 지워지지 않는다.** 갈림길에 들어설 때마다 그 순간이 저장되고,
패배 화면에서 *그 갈림길로 돌아간다* 를 고르면 그 길에 들어서기 직전 상태
(체력·골드·덱·유물 전부)로 되돌아간다. 창을 닫았다 와도 이어진다.

## 규칙 요약

- **기(氣)** 는 매 턴 3으로 회복된다. 카드 비용으로 쓴다.
- **방어도**는 *내 턴이 시작될 때* 사라진다. 적의 공격을 먼저 받아낸다.
- 적 머리 위 아이콘은 **다음 턴에 할 행동**이다. 숫자에 마우스를 올리면 상세히 보인다.
- **힘**은 공격 피해를, **민첩**은 방어도를 올린다.
  **취약**은 받는 피해 +50%, **약화**는 주는 피해 −25%, **중독**은 방어도를 무시한다.

## 들어 있는 것

| | |
|---|---|
| 카드 | 56종 (공격·기술·심법·특별·저주) + 전부 강화(+) 버전 |
| 유물 | 28종 — 훅 기반으로 동작 |
| 물약 | 12종 |
| 요괴 | 30종 — 잡졸 20, 엘리트 6, 보스 4 (구미호 · 산군 · 흑룡 · 염라) |
| 사건 | 9종의 갈림길 이벤트 |
| 구성 | 3막 × 12층 분기 지도 + 보스, 승리 후 **환생**(NG+) 무한 |

### 등급

부적에는 등급이 있고, 높을수록 카드가 눈에 띄게 강조된다.

| 등급 | 나오는 곳 |
|---|---|
| 4등급 | 시작 덱 |
| 3등급 · 2등급 · 1등급 | 전투 보상, 상점 (엘리트·보스일수록 좋은 것이 나온다) |
| **S급** | 특별 상자에서만. 카드에 **불이 붙는다** |
| **SSX급** | 특별 상자에서 아주 드물게. `없을 무(無)` — 대상의 이로운 효과와 방어도를 없애고 남은 체력의 절반을 없앤다 |
| ?급 | 아직 세상에 없다. 상자에서도 나오지 않는다 |

### 특별 상자

지도에 파랗게 빛나는 `匣` 노드. **지금은 시험 중이라 무료**로 열 수 있다.
상자에서는 **다이아 · 특별 카드 · 물약 · 보물** 중 하나가 나오고, 큰 상자일수록 좋은 것이 나온다.
다이아는 훗날 상자 값으로 쓰인다.

### 도감

여러 판에 걸쳐 발견한 부적·유물·요괴가 영구히 기록된다 (타이틀 → 도감).
부적은 등급별로 나뉘어 있고, 누르면 **기본과 강화 버전을 나란히** 볼 수 있다.

보스는 단순히 세기만 한 게 아니라 고유 기믹이 있다.

- **구미호** — 턴마다 꼬리가 하나씩 깨어나 힘이 계속 오르고, 체력 절반에서 각성한다
- **산군** — 4턴마다 기를 모아 다음 턴에 40이 넘는 **승천격**을 꽂는다. 보고 대비하라는 뜻이다
- **구천의 흑룡** — 4턴마다 흑염을 응축했다가 46짜리 브레스를 뿜는다. 절반에서 폭주에 들어간다
- **염라** — 세 턴마다 힘이 오르고, 다섯 턴마다 최후의 판결을 내린다. 절반을 넘기면 명부가 스스로 회복한다

3막 보스는 흑룡과 염라 중 어느 쪽이 나올지 판마다 달라진다.

## 구조

단일 HTML이지만 안은 구획이 나뉘어 있다.

```
0.  코어      난수(시드 기반 mulberry32), WebAudio 합성, 먹물 파티클, 툴팁
              — 소리는 master→컴프레서 뒤에 컨볼버 잔향 send 를 두고,
                같은 효과음도 매번 음정·길이를 흔들어 기계적으로 들리지 않게 한다
1.  상태이상  20종의 버프/디버프 정의 (이름·설명·감소 규칙)
3.  카드      defCard — 수치 v(u) 하나로 설명문과 실제 효과를 함께 만든다
4.  유물      defRelic — battleStart/turnStart/modAtk/modTaken… 훅으로 개입
5.  물약      defPot
6.  적        defEnemy — 행동표 + next(e) AI. 의도(intent)는 미리 뽑아 공개한다
7.  전투 엔진 피해 계산 → 방어도 → 상태이상 → 사망 처리, async 턴 진행
8.  렌더링    부채꼴 손패, 조준 베지어 화살, 데미지 숫자, 화면 흔들림
9.  지도 생성 6개의 등산로를 굴려 만드는 분기 그래프 (간선이 교차하지 않는다)
10~14         진행·보상·상점·야영지·사건·결과·타이틀
```

카드를 하나 더 넣고 싶으면 `defCard({...})` 한 덩어리만 추가하면 된다.
보상 풀·상점 재고에 자동으로 편입된다. 적도 `defEnemy` + `ENCOUNTERS` 등록이면 끝.

## 검증

헤드리스 Chromium으로 아래를 전부 돌렸고, 모두 오류 0건이다.

| 검사 | 결과 |
|---|---|
| 카드 56종 × 강화 전/후를 실제 전투에서 사용 | 112 / 112 |
| 적 30종의 모든 행동 실행 (가시 반사 경로 포함) | 88개 행동 |
| 적 AI가 400턴 동안 유효한 행동만 고르는지 | 이상 없음 |
| 유물 28종의 전 훅 + 물약 12종 사용 | 이상 없음 |
| 지도 200회 생성 — 고아 노드 / 막다른 길 / 보스 도달 불가 | 0건 |
| 1~3막 전 조우 자동 플레이 | 전부 정상 종료 |
| 지도 100회 생성 시 특별 상자 노드 보장 | 100 / 100 |
| 쓰러진 뒤 되돌아가기 — 체력·골드·덱·진행도 복원 | 정확히 일치 |
| 타이틀 → 지도 → 전투 → 보상 → 이벤트 완주 (실제 클릭) | 정상 |
| 1막 → 2막 → 3막 → 승리 → 환생 → 저장/이어하기 | 정상 |
| 효과음 20종 · 잔향 · 배경 바람 | 전부 정상 재생 |

이 과정에서 실제로 잡은 버그들:

- 전투가 끝나 상태가 비워진 뒤 마우스 이벤트·사망 처리가 이어져 터지던 크래시 2건
- 물약 아이콘이 상단바의 밝은 글자색을 물려받아 보이지 않던 문제
- 손패가 화면 아래로 잘리고, 방어도 배지가 상태이상 표시와 겹치던 문제
- **보상에서 카드를 고르면 보상 화면 자체가 사라져 진행이 막히던 문제** —
  오버레이를 화면(교체형)과 모달(중첩형) 두 계층으로 분리해 해결했다.
  같은 이유로 Esc는 이제 모달만 닫는다.
