# 손전화판 (mobile.html)

`game/mobile.html` 은 손으로 짓지 않는다. `game/index.html` 을 그대로 읽어
「손전화 겉옷」 한 겹만 덧대어 만든다.

```
node game/build-mobile.mjs
```

index.html 을 고쳤으면 이 한 줄을 다시 돌려 mobile.html 을 새로 뽑는다.
mobile.html 을 직접 고치지 말 것 — 다음 빌드에 지워진다.

## 덧대는 것

### 좁은 화면용 CSS
- `max-width:1000px` 또는 `max-height:560px` — 부적·요괴·단추를 줄인다
- `max-width:560px` — 한 번 더 줄인다
- `orientation:portrait` 이고 `max-width:620px` — 위아래로 다시 쌓는다
  - 윗줄이 두 줄까지 접힌다
  - 요괴가 위, 나는 그 아래 (`#field` 를 `column-reverse` 로)
  - 아랫판을 세 층으로: 기합·기·팻 / 부적 / 뽑을더미·턴종료·버린더미

### 손가락용 JS
- 겨냥선이 손가락을 따라오게 (본판은 `mousemove` 만 듣는다)
- 빈 곳을 누르면 고르기가 풀린다 (오른쪽 단추가 없으므로)
- 두 번 두드려 확대하는 것과 당겨 새로 고치는 것을 막는다
- 파편 상한을 90 으로 낮춘다
- 세로로 들면 「가로로 돌려 주십시오」를 한 번 띄운다 (닫으면 안 뜬다)
- 주소창이 오르내려도 판이 잘리지 않게 `--vh` 를 갱신한다

## 재 본 것

| 390×844 (세로) | 0 |
