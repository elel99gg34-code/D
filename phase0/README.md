# Phase 0 — 아파트 실거래가 API 검증

계획서(`../PLAN.md`) Phase 0 단계: 국토교통부 실거래가 API가 실제로 원하는 데이터를 주는지 확인한다.
**여기서 확인되면 Phase 1(수집 파이프라인)로 진행한다.**

## 1. API 키 발급 (직접 해야 하는 유일한 단계, 약 10분)

1. [공공데이터포털](https://www.data.go.kr) 회원가입 후 로그인
2. 검색창에 **"아파트 매매 실거래가"** 검색 → **국토교통부_아파트 매매 실거래가 자료** (오픈 API) 선택
3. **활용신청** 클릭 — 활용목적은 "웹 서비스 개발" 등으로 작성, **자동승인**임
4. 마이페이지 → 활용신청 목록에서 **일반 인증키(Decoding)** 복사
   - 발급 직후에는 서버 반영 전이라 인증 오류가 날 수 있음 → **최대 1시간 후 재시도**
5. 개발계정 트래픽: **일 1,000회** (검증에는 충분, 운영 전환 시 증량 신청)

같은 계정으로 나중에 전월세 API(`국토교통부_아파트 전월세 자료`)도 추가 신청 가능.

## 2. 실행

```bash
pip install requests   # 대부분 이미 설치되어 있음

export SERVICE_KEY="발급받은_일반인증키_Decoding"

# 강남구(11680) 2025년 6월 거래
python3 phase0/apt_trade.py --lawd-cd 11680 --deal-ymd 202506

# 다른 지역 예: 11110 종로구, 11710 송파구, 41135 성남 분당구, 26350 부산 해운대구
```

키 없이 파서/리포트 로직만 확인하려면:

```bash
python3 phase0/apt_trade.py --sample
```

## 3. 스크립트가 확인해주는 것 (Phase 0 체크리스트)

- [ ] API 호출 성공 (인증키 정상 동작)
- [ ] 필수 필드 9종(단지명, 거래금액, 거래일, 전용면적, 층, 법정동, 건축년도) 결측 여부
- [ ] 거래금액 문자열("182,500")의 숫자 변환 가능 여부
- [ ] 지역·월별 데이터 건수 (totalCount)

마지막 줄에 `✅ Phase 0 통과` 또는 `⚠ 이슈 있음` 판정이 출력된다.

## 4. 알아둘 것

- **엔드포인트**: `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`
  (구 `openapi.molit.go.kr` 주소는 폐지된 구버전이니 옛날 블로그 글 주의)
- **파라미터**: `LAWD_CD` = 법정동코드 앞 5자리, `DEAL_YMD` = YYYYMM
- **갱신 주기**: 실거래 신고 후 반영이라 당월 데이터는 계속 추가됨 → 수집 파이프라인에서 최근 2~3개월은 재수집 필요 (Phase 1 설계에 반영)
- **이 원격 세션의 네트워크 정책은 `apis.data.go.kr`를 차단**하므로, 실제 호출은 로컬 PC에서 실행하거나 세션 환경의 네트워크 허용 목록에 도메인을 추가해야 한다.
- 인증키는 절대 커밋하지 말 것 (`.gitignore`에 `.env` 등록됨)
